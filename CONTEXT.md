# Iterato

Plateforme de recrutement spécialisée DevOps / SRE / Platform Engineering. Deux entités métier : les Candidats (talents) et les Entreprises (clients). Pas de modèle d'offre d'emploi — les postes sont du contenu statique.

## Language

**Candidat** :
Un professionnel qui rejoint le vivier de talents d'Iterato, soit en postulant à une offre, soit en rejoignant la communauté.
_Avoid_ : Talent, postulant, applicant

**Entreprise** :
Une société qui cherche à recruter via Iterato et décrit le profil souhaité.
_Avoid_ : Client, company, compte

**Entry Point** :
Le motif d'entrée d'un candidat — `community` (rejoindre le réseau) ou `job_application` (postuler à une offre précise).
_Avoid_ : Source, canal, type

**Source** :
Le canal par lequel un candidat a été capté — `website` (formulaire public), `linkedin`, `email`, `event`, `referral`, `manual` (saisie admin).
_Avoid_ : Canal, origine, provenance
